# Project Geordi
**A world where a disability doesn't mean "you can't."**

---

## Why Geordi Exists

The web wasn't built with everyone in mind — and accessibility still relies too much on individual developers "doing the right thing." That's not sustainable. Accessibility shouldn't depend on empathy or budget cycles. It should be built into the fabric of how we experience the web.

**Geordi** exists to bridge that gap.

Instead of waiting for every developer to fix their markup, Geordi augments the browsing experience directly — reading page content aloud, helping users navigate structure, and (optionally) using AI to summarize and interact with pages in plain English.

---

## Our Mission

> **To make the entire web navigable, understandable, and usable for every human being, regardless of ability or code quality.**

Geordi is an open, community-driven browser extension that:

- Reads page content aloud using the Web Speech API — free, local, no API keys
- Helps users navigate page structure (headings, links) without relying on site markup quality
- Optionally offers AI-powered summarization and plain-English navigation (BYOK or paid tier)
- Works while you browse — no CLI, no screenshots, no waiting

---

## Core Principles

### 1. Accessibility is a right, not a feature.
Geordi will never gate core accessibility behind a paywall, subscription, or proprietary lock-in. Reading a page aloud is always free.

### 2. Transparency over performance.
Users should *see* what Geordi is doing — not trust a black box.

### 3. Data dignity.
User data and preferences belong to the user. Local-first is the default. Core reading requires no network.

### 4. Respect for the web.
We augment, not alter. Geordi never breaks underlying site logic or monetization.

### 5. Open collaboration.
Accessibility experts, disabled users, and developers are all first-class contributors.

---

## What We're Building

A browser extension that:

1. **Reads** page content and selections aloud via Web Speech API
2. **Navigates** page structure — headings, links, skip-to-main (Phase 2)
3. **Summarizes** content via optional AI (Phase 3, BYOK or paid)
4. **Acts** on plain-English commands with explicit user confirmation (Phase 3)

We started with reading. We'll grow together.

---

## Free vs Optional Paid Features

| Always free | Optional (Phase 3+) |
|---|---|
| Read page / selection aloud | Page summarization |
| Play / pause / stop / speed | Plain-English navigation |
| System voices | Premium human-sounding voices (Phase 4) |
| Heading / link navigation | |

AI features cost tokens — users can bring their own API key or subscribe to Geordi Cloud (future).

## How to Contribute

You don't need to be an AI researcher to help. Accessibility is about empathy, not credentials.

- Test the extension and give feedback
- Improve UX for screen readers or keyboard-only users
- Translate docs or help with communication
- Contribute code for extraction, speech, or UI
- Write tutorials or documentation

Start with [CONTRIBUTING.md](CONTRIBUTING.md) or [AGENTS.md](../AGENTS.md) for AI-assisted development.
